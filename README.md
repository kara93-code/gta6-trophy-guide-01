Leonida Platinum is a fully offline GTA VI trophy guide and tracker for PlayStation 5: all 55 official trophies (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden) with their official names, descriptions, and grades, each paired with an original guide that cites its sources. It includes a persistent checklist (localStorage) with export/import, filters by type (story, missable, collectibles, activities, online), a spoiler setting that hides story trophy names and descriptions until earned, a step-by-step roadmap to platinum, missable flags, a "Next up" planner, and per-trophy notes.

## Run it

```sh
cd app && python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser. There is no build step: the app is plain static files and works fully offline.
